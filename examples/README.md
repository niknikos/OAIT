# Examples

Runnable `.R` scripts that mirror cookbook recipes, one per slug
(`cookbook/<slug>.md` ↔ `examples/<slug>.R`).

A script is added here only once its recipe has been **run against real files** and marked
`status: validated` in the cookbook. The scripts read paths from `~/.oait/config.json` and
never contain data, positions, or dataset identifiers that are themselves sensitive.

At version 0.1 this folder is intentionally empty: the seed recipes are drafts.
